# LES：前瞻专家调度

[English](lookahead-expert-scheduling.md) | 中文

LES 将 **MiniCPM-V 4.7 35B-A3B** 的路由专家由内存改为从闪存按需读取，并将由此产生的读取与已在进行的 GPU 计算重叠。读 1 个专家（约 1.00 ms）与算 1 整层的开销相当（约 1.15 ms），因此按需读取会使磁盘延迟成为吞吐的瓶颈。

## 亮点

- **前瞻专家** - 以第 L 层的隐状态提前一层预测第 L+1 层的 top-k；预测所得的专家在第 L 层计算期间从 SSD 预读，无需额外训练，输出保持不变
- **调度优化** - 更少且更大的读取、直接写入 GPU 可见内存、绕开页缓存、加宽逐层专家窗口、预读常用专家
- **精细化量化** - 通过参数搜索为各张量组分配精度，降低字节占比较大的张量组的精度，同时保留对精度敏感的张量组
- **DSpark** - 一个投机解码阶段，在 decode 路径上与 LES 并行
